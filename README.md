### Hi, I'm HumSaw

I build things that are fun to reverse-engineer: probabilistic game engines, self-learning simulations, and cross-platform desktop tools.

**What I work with:** TypeScript, Next.js, React, Electron, Node.js

**Projects worth a look:**

- [**battleship-math-model**](https://github.com/HumSaw/battleship-math-model) — a Battleship advisor built on real math: constrained fleet enumeration, Sequential Importance Sampling, and bounded expectimax endgames. Runs in a Web Worker, UI in 10 languages. [Live demo](https://admiral-weld.vercel.app)
- [**yt-live-wallpaper**](https://github.com/HumSaw/yt-live-wallpaper) — turn any YouTube video into a live 4K desktop wallpaper. Electron app for Windows, macOS, and Linux with multi-monitor support and smart pausing.
- [**erdalion-simulation**](https://github.com/HumSaw/erdalion-simulation) — 10 fantasy factions with independent Q-learning policies fight, trade, and marry their way through history. No scripted behavior.
- [**evervale-kingdom**](https://github.com/HumSaw/evervale-kingdom) — a kingdom-building strategy game with procedurally generated enemies, running entirely in the browser.

I care about the parts most people skip: engine correctness, deterministic tests, honest READMEs, and commit histories you can actually read.
